# Exam Score Prediction Using Machine Learning

## Project Overview
This project predicts students' exam scores using machine learning techniques based on academic and lifestyle-related factors.

## Objectives
- Analyze student performance data.
- Identify factors affecting exam scores.
- Build a machine learning prediction model.
- Evaluate model performance.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset
The dataset contains student information such as:
- Study hours
- Attendance percentage
- Previous scores
- Sleep hours
- Exam score

## Machine Learning Algorithm
Random Forest Regression.

## Project Files
- `exam_score_prediction.ipynb` – Main Jupyter Notebook.
- `student_performance_messy.csv` – Dataset.
- `README.md` – Project documentation.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install pandas numpy matplotlib scikit-learn`
3. Open Jupyter Notebook.
4. Run `exam_score_prediction.ipynb`.
